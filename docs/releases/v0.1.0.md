The first version of Stepcast.

- Record your whole screen, or just an area or a window, as MP4, with your microphone
- Automatic labels for browser steps: "Click 'Products'", "Enter 'Username'", "Check '…'" (English and Danish)
- Webcam panel next to the screen, with adjustable size and side
- Click ripple and highlight around the clicked element
- Labels for keyboard shortcuts ("Press Ctrl+S"), which you can turn off
- Optional zoom in on clicks
- Interrupted recordings are recovered the next time you open Stepcast
- Password fields (and fields you pick) are blurred
- Edit labels, trim and pause before you export
- Export a step-by-step guide as HTML and Markdown
- Updates itself: you'll see "Update available" when a new version is out
