Recording on macOS works again once you've given Stepcast access.

- **macOS permissions:** Stepcast is now signed as a whole app, so macOS remembers the Screen Recording, Camera
  and Microphone access you give it. Before, it could ask on every recording and the recording never started.
- **After this update (and each future one), macOS asks for access once more.** Allow Screen Recording, Camera
  and Microphone in **System Settings → Privacy & Security**, then restart Stepcast. If it keeps asking, see
  [macOS keeps asking for permissions](https://github.com/rene-poulsen/stepcast#macos-keeps-asking-for-permissions).
