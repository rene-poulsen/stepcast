The first version of Stepcast: a free screen recorder for support videos that labels every step you take in
the browser.

**What it does**

- Record your whole screen, or just an area or a window, as MP4, with your microphone
- Automatic labels for browser steps: "Click 'Products'", "Enter 'Username'", "Check '…'" (English and Danish)
- Labels for keyboard shortcuts ("Press Ctrl+S"), which you can turn off
- Webcam panel next to the screen, with adjustable size and side
- Click ripple and highlight around the clicked element, and optional zoom in on clicks
- Password fields (and fields you pick) are blurred
- Edit labels, trim and pause before you export
- Export a step-by-step guide as HTML and Markdown
- Interrupted recordings are recovered the next time you open Stepcast
- Updates itself: you'll see "Update available" when a new version is out

**Install**

- **Windows:** download `Stepcast_0.1.0_x64-setup.exe`. If Windows says "Windows protected your PC", click
  **More info → Run anyway** (the app isn't code-signed yet).
- **macOS:** download `Stepcast_0.1.0_universal.dmg`. If macOS says it can't be opened, go to **System Settings →
  Privacy & Security → Open Anyway**.
- Then open Stepcast and follow **Install the browser extension** (Chrome, Edge, Brave or Arc).
